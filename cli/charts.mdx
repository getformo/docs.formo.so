The `formo charts` command group manages charts within dashboard boards. Every chart command is scoped to a board with `--board-id`.

## `formo charts list`

List charts for a board. Returns lightweight summaries by default; pass `--results` to execute each chart’s query and include full results.

<Note>
Requires `boards:read` scope on your API key.
</Note>

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `--board-id` | `string` | ✅ | Board ID to list charts from |
| `--results` | `boolean` | ❌ | Execute each chart’s query and include results (slower; hits the analytics backend) |
| `--page` | `number` | ❌ | Page number, 1-indexed |
| `--size` | `number` | ❌ | Page size |

```bash
formo charts list --board-id board_abc123 --size 25
```

## `formo charts query <chartId>`

Execute a saved chart query after substituting `{{date_from}}` and `{{date_to}}`.

<Note>
Requires `boards:read` scope and a chart query that uses both date variables.
</Note>

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `--board-id` | `string` | ✅ | Board ID the chart belongs to |
| `--date-from` | `string` | ✅ | Date variable value, `YYYY-MM-DD` |
| `--date-to` | `string` | ✅ | Date variable value, `YYYY-MM-DD` |

```bash
formo charts query chart_abc123 --board-id board_abc123 --date-from 2026-04-01 --date-to 2026-04-30
```

## `formo charts create`

Create a chart. A chart is a title and a spec: what it computes (`spec.query`) and how it is drawn (`spec.view`, a Vega-Lite subset). See [Create Chart](/api/boards/create-chart) for the full spec.

<Note>
Requires `boards:write` scope on your API key. Needs CLI 2.0.0 or later.
</Note>

### Options

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `--board-id` | `string` | ✅ | Board ID to add the chart to |
| `--body` | `string` | ❌ | Raw JSON chart body `{ title, description, spec }`. Typed flags override matching keys. |
| `--title` | `string` | ❌ | Chart title |
| `--description` | `string` | ❌ | Optional chart description |
| `--spec` | `string` | ❌ | Full chart spec JSON: `{"version":1,"query":{...},"view":{...}}` |
| `--sql` | `string` | ❌ | SQL for a SQL chart. Sets `spec.query` to `{"kind":"sql","sql":...}` |
| `--view` | `string` | ❌ | View JSON: marks `bar`, `line`, `area`, `arc`, `text`, or `x-table`, `x-funnel`, `x-retention`, `x-sankey` |
| `--settings` | `string` | ❌ | JSON for `spec.query.settings`. Paths need `anchors`; retention needs an `entryFilter` key. |

Provide either `--body` or chart fields such as `--title`, `--spec`, `--sql` and `--view`. Every column the view names must be in the SQL result.

### Examples

```bash
# Line chart from SQL and a view
formo charts create \
  --board-id board_abc123 \
  --title "Daily active users" \
  --sql "SELECT toDate(timestamp) AS date, countDistinct(address) AS users FROM events GROUP BY date ORDER BY date" \
  --view '{"mark":"line","encoding":{"x":{"field":"date"},"y":{"field":"users"}}}'

# Table from raw JSON
formo charts create \
  --board-id board_abc123 \
  --body '{"title":"Recent events","spec":{"version":1,"query":{"kind":"sql","sql":"SELECT * FROM events LIMIT 10"},"view":{"mark":"x-table"}}}'

# Open-ended User Paths chart (no SQL)
formo charts create \
  --board-id board_abc123 \
  --title "Post-connect paths" \
  --spec '{"version":1,"query":{"kind":"paths","settings":{"anchors":[{"type":"event","event":"connect"}],"maxSteps":5,"nodesPerStep":3}},"view":{"mark":"x-sankey"}}'
```

## `formo charts update <chartId>`

Update an existing chart. The CLI fetches the chart and sends the full body the API needs. `--sql`, `--view` and `--settings` change one part of the current spec and keep the rest.

<Note>
Requires `boards:write` scope on your API key.
</Note>

```bash
formo charts update chart_abc123 --board-id board_abc123 --title "Updated chart name"

# Change only how the chart is drawn
formo charts update chart_abc123 --board-id board_abc123 \
  --view '{"mark":"bar","encoding":{"x":{"field":"date"},"y":{"field":"users"}}}'
```

The same options as `create` are available.

## `formo charts move <chartId>`

Move a chart to another board.

<Note>
Requires `boards:write` scope on your API key.
</Note>

```bash
formo charts move chart_abc123 --board-id source_board --target-board-id target_board
```

---

## `formo charts duplicate <chartId>`

Duplicate a chart within its board. The CLI returns the new chart ID.

<Note>
Requires `boards:write` scope on your API key.
</Note>

```bash
formo charts duplicate chart_abc123 --board-id board_abc123
```

---

## `formo charts reorder`

Reorder charts in a board.

<Note>
Requires `boards:write` scope on your API key.
</Note>

```bash
formo charts reorder --board-id board_abc123 --chart-ids chart_a,chart_b,chart_c
```

`--chart-ids` may be comma-separated text or a JSON array.

---

## `formo charts delete <chartId>`

Delete a chart.

<Note>
Requires `boards:write` scope on your API key.
</Note>

```bash
formo charts delete chart_abc123 --board-id board_abc123
```

<Warning>
Deleting a chart is permanent.
</Warning>
