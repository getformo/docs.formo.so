<Warning>
  The BI integration is deprecated. The BI Read Key is no longer available in the project settings, and new connections are not supported.
</Warning>

The BI integration let you connect a BI tool or SQL client to Formo with a BI Read Key. A BI Read Key expired after one week, so a connection that used one no longer works.

## What to use now

| You want to | Use |
| --- | --- |
| Write SQL and build charts in Formo | The [Explorer](/features/product-analytics/explore) and [Charts](/features/product-analytics/charts) |
| Run SQL from your own code or a scheduled job | The [Query API](/api/overview#query-api) with a workspace API key |
| Explore your data from Claude, Cursor, or another AI tool | [MCP](/mcp/overview) |
| Use a BI tool such as Metabase, Grafana, or Tableau | [Data sync](/data/data-sync): export to Google Cloud Storage or Amazon S3, load the files into your warehouse, and connect the BI tool there |

## Why it was deprecated

A BI tool sent its SQL straight to the database, with no Formo service in between. Formo could not apply the same query handling and safeguards there that the Explorer, the Query API, and MCP have. Those three give you the same data with full SQL support.

If you depend on a direct BI connection, [contact support](https://formo.so/support).
