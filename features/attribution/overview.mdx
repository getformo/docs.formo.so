Attribution connects the source that brought someone to your app with what they do next, from the first visit and wallet connect through transactions, volume, and revenue. This matters because traffic alone cannot tell you which channels attract valuable onchain users or deserve more investment.

Formo captures marketing context from browser referrers, referral codes, ad click IDs, UTM parameters, and mobile links, then connects it to sessions and users with first-touch and last-touch properties. It also detects builder codes for transaction-level onchain attribution.

## Attribution sources

| Source | What it answers |
| --- | --- |
| **Channels** | Which high-level acquisition category—paid search, organic social, AI, email, direct, and others—drove activity? |
| **Referrers** | Which external site or page sent the visitor? |
| **Referrals** | Which referral or partner code brought the user? |
| **Ads** | Which paid network acquired the session or user? |
| **UTM** | Which source, medium, campaign, content, or term drove the visit? |
| **Builder codes** | Which app built an EVM transaction, based on its ERC-8021 calldata suffix? |
| **Mobile attribution** | Which deep link, universal link, or Android install referrer brought the app user? |
