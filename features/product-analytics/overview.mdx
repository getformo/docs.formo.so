## Features

- 🎯 <a href="/features/product-analytics/key-metrics">**Key metrics.**</a> Track visitors, pageviews, wallets, transactions, and revenue with complete channel and campaign attribution.
- 🏃‍♀️‍➡️ <a href="/features/product-analytics/activity">**Activity feed.**</a> Real-time event stream for understanding user behavior across web, mobile, and onchain sources.
- 🌍 <a href="/features/product-analytics/live-view">**Live view.**</a> View live users and activity on an interactive, real-time global map.
- ⚡️ <a href="/features/product-analytics/custom-events">**Custom events.**</a> Track key touchpoints and feature adoption on your crypto app.
- 🌐 <a href="/features/product-analytics/contract-events">**Contract events.**</a> Track smart contract events without running your own indexer.
- 📈 <a href="/features/product-analytics/charts">**Dashboards.**</a> Create custom charts and reports and share them with your team.
- 🔍 <a href="/features/product-analytics/explore">**Explorer.**</a> Run custom SQL queries on your analytics data.
- 📊 <a href="/features/product-analytics/funnels">**Funnels.**</a> Follow your users from first visit to conversion with multi-step funnels.
- 🧭 <a href="/features/product-analytics/flows">**Flows.**</a> Analyze user paths and flows to see what users do next.
- 📅 <a href="/features/product-analytics/retention">**Retention.**</a> Measure which user cohorts retain and churn over time.
- 🔔 <a href="/features/product-analytics/alerts">**Alerts.**</a> Get notified of high-value users and important events in realtime.
- 💡 <a href="/features/product-analytics/insights">**Insights.**</a> Get weekly product insights on acquisition, activation, and churn.
- ✨ <a href="/features/product-analytics/ai">**Ask AI.**</a> Use natural language to ask any questions about your data.
- ⚙️ <a href="/install">**Autocapture.**</a> Automatically track page views, wallet connects, and transactions with zero code.

## FAQ

<AccordionGroup>
  <Accordion title="Can I track users across my website and my app?">
    Yes. Cross-subdomain tracking is enabled by default (`crossSubdomainCookies: true`), so visitor identity is shared across all subdomains of your root domain out of the box. See the [Web SDK documentation](/sdks/web#cross-subdomain-tracking) for details.
  </Accordion>
  <Accordion title="How does Formo count unique visitors?">
    Formo generates an anonymous visitor ID (UUID) stored in a first-party cookie on your domain. This ID is not linked to any personal information - no IP addresses or device fingerprints are used. A server-side daily-rotating hash is also used for session deduplication. See [what we collect](/data/what-we-collect) for details.
  </Accordion>
  <Accordion title="Can I write SQL queries against my analytics data?">
    Yes. Use the [Explorer](/features/product-analytics/explore) to run SQL queries directly against your analytics data. You can also use the [Query API](/api/query) or connect [BI tools](/data/bi) like Metabase or Grafana.
  </Accordion>
</AccordionGroup>
