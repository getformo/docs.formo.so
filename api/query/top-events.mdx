---
title: "Get Top Events"
description: "Retrieve the most frequent events over a selected date range, with optional event type filters."
openapi: "GET /v0/top_events"
---

Returns the most frequently fired events in the project, by total event count.

Pass `type=custom` to restrict results to custom events (events tracked via `formo.track(...)`). This replaces the previous `top_custom_events` endpoint.
